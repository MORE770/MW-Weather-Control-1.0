# MW Weather Control 1.0

**MW Weather Control** is a weather customization mod for **Need for Speed: Most Wanted (2005)**. It adds configurable rain and dry-weather cycles, changes road grip as the surface becomes wet or dries out, and provides an in-game settings menu.

**Supported game:** PC, version 1.3.

## Features

- Automatic rain and dry-weather cycles with adjustable duration.
- Gradual road wetting and drying, affecting vehicle grip.
- Adjustable wet-road handling settings.
- Rain controls directly in the menu: **ON**, **OFF**, or **AUTO**.
- In-game settings menu with English and Russian translations.
- Move, resize, or minimize the settings window.
- Adjust numeric settings with sliders, `−` / `+` buttons (one unit per click), or by typing a value.
- Settings are saved between sessions. No separate INI configuration is required.
- Police radio weather reports remain available automatically (no radio options in the menu).

## Installation

1. Make sure **Need for Speed: Most Wanted (2005) for PC, version 1.3** is installed.
2. Make sure an **ASI Loader** is installed in the game directory.
3. Copy `MW_WeatherControl.asi` into the game's `scripts` folder.
4. Launch the game and press **Ctrl + Shift + F2** to open the settings menu.

## In-game controls

| Action | Control |
|---|---|
| Open / close the menu | **Ctrl + Shift + F2** |
| Switch Russian / English | **F6** or the **RU / EN** button |
| Change a setting | Drag its slider, click `−` / `+`, or click the number to type |
| Cancel number editing | **Esc** |
| Move to the next numeric field | **Tab** |
| Move the window | Drag its title bar |
| Resize the window | Drag its bottom-right corner |
| Collapse the window | Click the `−` button in the title bar |

Use **RAIN ON**, **RAIN OFF**, and **AUTO** in the menu to control the weather manually or return to automatic cycles.

## Setting limits

| Setting | Range |
|---|---|
| Rain duration (minimum / maximum) | **1–60 minutes** |
| Dry-weather break (minimum / maximum) | **1–60 minutes** |
| Road wetting time | **1–60 seconds** |
| Road drying time | **1–60 seconds** |

# Русский

**MW Weather Control** — мод для **Need for Speed: Most Wanted (2005)**, позволяющий настраивать продолжительность дождя и сухой погоды, а также сцепление с дорогой при намокании и высыхании. Все основные параметры изменяются в меню прямо во время игры.

**Поддерживаемая версия игры:** PC, 1.3.

## Возможности

- Автоматическое чередование дождя и сухой погоды.
- Постепенное намокание и высыхание дороги с изменением сцепления.
- Настройка поведения автомобиля на мокрой дороге.
- Кнопки **RAIN ON / RAIN OFF / AUTO** для управления дождём.
- Внутриигровое меню на русском и английском языках.
- Перемещение, изменение размера и сворачивание окна.
- Ползунки, кнопки `−` / `+` с шагом 1 и ручной ввод чисел.
- Сохранение настроек между запусками без отдельного INI.
- Погодные радиопереговоры полиции сохранены и работают автоматически, но не отображаются в настройках.

## Установка

1. Убедитесь, что у вас **установлена Need for Speed: Most Wanted (2005) для ПК версии 1.3**.
2. Убедитесь, что в папке игры установлен **ASI Loader**.
3. Скопируйте `MW_WeatherControl.asi` в папку `scripts` в каталоге игры.
4. После установки запустите игру и нажмите **Ctrl + Shift + F2**, чтобы открыть меню настроек.

## Управление

| Действие | Клавиши / мышь |
|---|---|
| Открыть / закрыть меню | **Ctrl + Shift + F2** |
| Переключить язык | **F6** или кнопка **RU / EN** |
| Изменить число | Ползунок, кнопки `−` / `+` или ввод по нажатию на число |
| Отменить ввод | **Esc** |
| Следующее числовое поле | **Tab** |
| Переместить окно | Перетащить за заголовок |
| Изменить размер | Потянуть за правый нижний угол |
| Свернуть окно | Кнопка `−` в заголовке |

Кнопки **RAIN ON**, **RAIN OFF** и **AUTO** принудительно включают дождь, выключают его или возвращают автоматическую смену погоды.
