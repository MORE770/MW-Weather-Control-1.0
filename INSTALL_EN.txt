MW Weather Control 1.0 — Need for Speed: Most Wanted (2005)

INSTALLATION
1. Make sure the PC game version 1.3 (x86) is installed.
2. Make sure an ASI Loader is installed in the game directory.
3. Copy scripts\MW_WeatherControl.asi into the game's scripts folder.
4. Launch the game and press Ctrl + Shift + F2 to open the menu.

CONTROLS
- F6 or the RU/EN button switches languages.
- Use a slider, the -/+ buttons (1 unit per click), or click a number and type.
- Enter confirms; Esc cancels; Tab moves to the next numeric field.
- Drag the title bar to move the window and the bottom-right corner to resize it.

SETTINGS
- Rain duration and dry-weather intervals: 1–60 minutes.
- Road wetting and drying: 1–60 seconds.
- Police weather radio remains active; diagnostic logs are disabled by default.

The mod is version 1.0. The required game version is 1.3.
